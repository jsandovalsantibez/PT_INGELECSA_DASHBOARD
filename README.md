Sistema Web de Gestión de Proyectos y Tareas para Empresas Técnicas

Este proyecto consiste en una plataforma web desarrollada para optimizar la gestión de trabajos, el seguimiento de tareas y la toma de decisiones en empresas del rubro técnico-operacional. Fue desarrollado como parte de una colaboración freelance para una empresa especializada en sistemas de protección contra incendios.

🧩 Funcionalidades principales
Gestión de usuarios y roles (Gerente de operaciones, Técnicos de soporte)
Asignación y seguimiento de tareas por proyecto    
Calendario de planificación de tareas
Visualización de datos mediante gráficos interactivos
Carga de imágenes y documentación por tarea
Análisis de desempeño de tareas mediante dashboard
Módulo de autenticación seguro con control de permisos
Geolocalización de tareas en mapa

⚙️ Tecnologías utilizadas
Frontend: React.js + Vite + CSS
Backend: Node.js
Base de datos: Firebase (Firestore)
Control de versiones: Git & Git Bash
Diagramación y documentación: UML, BPMN (Bizagi, Draw.io)

🔐 Autenticación y Seguridad
El sistema implementa autenticación de usuarios mediante Firebase Authentication y maneja distintos niveles de acceso según el rol del usuario.

📊 Módulos de Visualización
Dashboard personalizado según tipo de usuario.

Vistas para tareas, formularios, perfiles, y reportes analíticos.

Mapas integrados para geolocalización de tareas.

🧪 Pruebas
Se aplicaron pruebas unitarias y funcionales para validar cada uno de los módulos del sistema, asegurando la integridad, rendimiento y experiencia del usuario.

🚀 Objetivo del proyecto
Entregar a pequeñas y medianas empresas del área técnica una herramienta adaptable, moderna y eficiente para la gestión de sus operaciones diarias, ayudando a digitalizar procesos y mejorar la productividad del equipo.
